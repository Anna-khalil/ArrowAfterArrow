# 一箭又一箭 ArrowAfterArrow

> 福州大学 2026 秋软件工程第二次个人作业  

一款基于 Python + Pygame 开发的箭头消除休闲小游戏。玩家需要观察箭头方向和相互阻挡关系，按照合适的顺序点击箭头，使所有箭头依次飞出棋盘。

## 游戏简介

棋盘中分布着若干带方向的箭头（上、下、左、右）。点击某个箭头后，程序检查该箭头前进方向上的路径：

- 如果箭头与棋盘边界之间**没有其他箭头阻挡**，该箭头飞出棋盘并被消除；
- 如果路径上**存在其他箭头**，该箭头不能被消除，并通过晃动和变色提示碰撞，同时消耗一次失误机会；
- 清除本关全部箭头后即可进入下一关；
- 失误次数耗尽时，本关失败，可重新开始。

## 开发环境

- **操作系统**：Windows 10/11
- **Python**：3.13.5
- **图形库**：Pygame 2.6.1
- **AIGC 工具**：Cursor、DeepSeek

## 安装和运行方法

### 1. 安装 Python

从 [Python 官网](https://www.python.org/downloads/) 下载并安装 Python 3.8 或更高版本。安装时勾选 "Add Python to PATH"。

### 2. 安装 Pygame

打开命令行（CMD 或 PowerShell），执行：

```bash
pip install pygame
```

### 3. 运行游戏

进入项目根目录，执行：

```bash
python main.py
```

## 游戏操作说明

| 操作 | 说明 |
|---|---|
| 鼠标左键点击箭头 | 尝试让该箭头沿方向飞出棋盘 |
| 「重新开始」按钮 | 当前关卡恢复初始状态 |
| 「撤销」按钮 | 撤销上一步成功消除操作 |
| 「提示」按钮 | 高亮显示一个可消除的箭头（AI 求解最优下一步） |
| 「AI 求解」按钮 | AI 自动演示通关步骤 |
| 「返回」按钮 | 返回关卡选择界面 |

## 功能列表

### 基础功能
- 图形化游戏界面（开始界面、游戏界面、通关/失败界面）
- 上、下、左、右四种方向箭头
- 鼠标点击选择箭头
- 四方向路径检测与阻挡判断
- 箭头飞出动画与碰撞反馈（晃动 + 变色）
- 失误次数显示与扣除
- 10 个可通关关卡，难度递增
- 通关/失败结果显示与关卡切换
- 重新开始功能

### 附加功能
- **撤销**：可回退上一步成功消除操作
- **提示**：AI 求解器计算最优下一步并高亮提示
- **AI 自动求解**：自动演示完整通关步骤
- **关卡选择**：选关界面，显示星级评价，未解锁关卡锁定
- **存档系统**：自动保存通关进度、最佳成绩、星级
- **计时与得分**：通关后根据用时和剩余失误计算得分与星级
- **继续游戏**：从上次进度继续

## 项目结构

```
ArrowAfterArrow/
├── main.py              # 程序入口，主循环与界面管理
├── constants.py         # 常量配置（颜色、尺寸、方向、字体）
├── arrow.py             # 箭头类（数据、动画、绘制）
├── board.py             # 棋盘类（网格管理、路径检测核心算法）
├── levels.py            # 10 个关卡数据
├── game_state.py        # 游戏状态管理（关卡、失误、撤销、计分）
├── solver.py            # AI 求解器（DFS 回溯 + 记忆化）
├── save_manager.py      # 存档管理（JSON 读写）
├── ui.py                # 界面模块（按钮、开始/选关/游戏/结果界面）
├── tests/
│   └── verify_levels.py # 关卡可解性验证脚本
├── saves/               # 存档目录（运行时自动生成，不入库）
├── .gitignore
└── README.md
```
